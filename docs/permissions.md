# Claude Agent Permission System

This document describes the unified permission system for Claude Agent in Emacs.

## Overview

All permission decisions for Claude agents are now handled by Emacs using a
rules-based system. The permission system evaluates rules in order:

1. **Buffer-local rules** (`claude-agent-permission-rules-local`) - Agent-type specific
2. **Project rules** (`claude-agent-project-permission-rules`) - From `.claude/settings.local.el`
3. **Global rules** (`claude-agent-permission-rules`) - User's `init.el`
4. **Fall through to interactive prompt** - If no rule matches

## Rule Format

Each rule is a plist with the following keys:

```elisp
(:match MATCHER
 :action :allow | :deny | :prompt
 :scope :once | :session | :always    ; for :allow only
 :reason "message")                    ; for :deny only
```

### Matchers

| Matcher | Description |
|---------|-------------|
| `t` | Always matches (catch-all) |
| `(:tool TOOL-NAME)` | Match tool name exactly |
| `(:tool-regex REGEX)` | Match tool name by regex |
| `(:path-prefix PATH)` | Match file operations under PATH |
| `(:path-regex REGEX)` | Match file paths by regex |
| `(:predicate FN)` | Call `(FN TOOL-NAME TOOL-INPUT)`, match if truthy |
| `(:and MATCHER ...)` | All matchers must match |
| `(:or MATCHER ...)` | Any matcher must match |
| `(:not MATCHER)` | Invert match |

### Actions

| Action | Description |
|--------|-------------|
| `:allow` | Auto-allow the tool use (with optional `:scope`) |
| `:deny` | Auto-deny with optional `:reason` |
| `:prompt` | Fall through to interactive UI |

### Scopes (for `:allow`)

| Scope | Description |
|-------|-------------|
| `:once` | Allow just this invocation |
| `:session` | Allow for the rest of the session |
| `:always` | Always allow (persisted to project settings) |

## Examples

### Deny all permissions (oneshot agents)

```elisp
(setq-local claude-agent-permission-rules-local
  '((:match t
     :action :deny
     :reason "Oneshot agent - use pre-authorized tools only")))
```

### Allow read-only operations

```elisp
(setq claude-agent-permission-rules
  '((:match (:tool-regex "^Read\\|^Glob\\|^Grep")
     :action :allow
     :scope :session)
    (:match t :action :prompt)))
```

### Confine agent to a directory (worktree)

```elisp
(setq-local claude-agent-permission-rules-local
  '(;; Allow file operations in the worktree
    (:match (:and (:tool-regex "Edit\\|Write\\|Read")
                  (:path-prefix "/path/to/worktree/"))
     :action :allow
     :scope :session)
    ;; Deny file operations outside the worktree
    (:match (:and (:tool-regex "Edit\\|Write\\|Read")
                  (:not (:path-prefix "/path/to/worktree/")))
     :action :deny
     :reason "Cannot edit files outside assigned worktree")
    ;; Prompt for everything else
    (:match t :action :prompt)))
```

### Use a predicate for complex logic

```elisp
(defun my-dangerous-command-p (tool-name tool-input)
  "Return non-nil if this is a dangerous bash command."
  (and (string= tool-name "Bash")
       (let ((cmd (plist-get tool-input :command)))
         (string-match-p "\\brm\\b\\|\\bsudo\\b" cmd))))

(setq claude-agent-permission-rules
  '((:match (:predicate my-dangerous-command-p)
     :action :deny
     :reason "Potentially dangerous command - manual review required")
    (:match t :action :prompt)))
```

## Project Settings

Project-level permission rules are stored in `.claude/settings.local.el`:

```elisp
;;; .claude/settings.local.el --- Project permission rules -*- lexical-binding: t; -*-

;; Auto-generated by claude-agent permission prompts.
;; You may edit this file manually.

(setq claude-agent-project-permission-rules
      '((:match (:tool "Read")
         :action :allow
         :scope :always)
        (:match (:and (:tool-regex "Edit\\|Write")
                      (:path-prefix "/home/user/project/"))
         :action :allow
         :scope :always)))
```

### Loading Project Settings

Project settings are loaded automatically when a Claude agent buffer is created.
You can also manually reload them:

```elisp
(claude-agent-load-project-settings)
```

### Saving Project Rules

When a user approves a permission with `:always` scope, it's automatically
saved to the project's `.claude/settings.local.el`:

```elisp
(claude-agent-save-project-rule '(:match (:tool "Read")
                                  :action :allow
                                  :scope :always))
```

### Editing Project Settings

Open the project settings file for manual editing:

```elisp
M-x claude-agent-edit-project-settings
```

## Path Extraction for MCP Tools

The permission system needs to know which arguments contain file paths for
`:path-prefix` and `:path-regex` matchers to work.

### SDK Tools

Built-in SDK tools have their path arguments registered in
`claude-agent-sdk-tool-path-args`:

```elisp
(defvar claude-agent-sdk-tool-path-args
  '(("Read" . ("file_path"))
    ("Edit" . ("file_path"))
    ("Write" . ("file_path"))
    ("Glob" . ("path"))
    ("Grep" . ("path"))
    ("NotebookEdit" . ("notebook_path"))))
```

### MCP Tools

For MCP tools defined with `claude-mcp-deftool`, use the `path` type for
arguments that contain file paths:

```elisp
(claude-mcp-deftool read-file
  "Read a file from disk."
  :function #'claude-mcp-read-file
  :needs-session-cwd t
  :args ((file-path path :required "Path to the file to read")))
```

The `path` type:
- Is exported as `string` to the MCP JSON schema
- Registers the argument in `claude-agent-mcp-tool-path-args`
- Enables `:path-prefix` matching for this tool

## API Reference

### Main Entry Point

```elisp
(claude-agent-permission-check TOOL-NAME TOOL-INPUT) -> plist
```

Returns a plist:
- `(:decision :allow :scope SCOPE :pattern PATTERN)` - Allow the tool
- `(:decision :deny :reason R)` - Deny with reason R
- `(:decision :prompt)` - Show interactive UI

### Wrapper Function

The `claude-agent-permission-handle-request` function wraps `claude-agent-permission-check`
and returns results in the format expected by the permission prompt handler:

```elisp
(claude-agent-permission-handle-request TOOL-NAME TOOL-INPUT) -> result

;; Returns one of:
;; (:allow :scope SCOPE :pattern PATTERN) - Auto-allow
;; (:deny :message MESSAGE)               - Auto-deny
;; nil                                    - Show interactive prompt
```
